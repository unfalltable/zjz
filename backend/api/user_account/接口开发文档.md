# 账号接口文档入口

账号系统现以用户提供的 **完整版账号登录模块.zip** 为准，唯一规范运行实现位于 `../account/`。

- [完整接口与安全契约](../account/README.md)
- [商城整合与部署接线](../../../docs/account-integration.md)
- [账号库新建结构与只读审核](../../sql/account/README.md)

原目录的 `user_account_api.js`、`server.cjs` 仅作为旧路径兼容导出，不包含另一套旧逻辑。默认启动命令为 `backend/api` 下的 `npm run start:account`，监听 `127.0.0.1:3002`；导入模块不自动连接数据库或启动监听。

`POST /api/account/me` 返回安全资料字段，`POST /api/account/logout` 撤销会话并清理 Cookie。这些远端新增/修复能力已在新版保留。旧 Token、验证码缓存不直接迁入新的隔离会话命名空间，切换服务后旧会话需要重新登录。

邮件、短信、OAuth 需要真实配置，未配置时不会报告发送或登录成功。压缩包中的开发数据库值、硬编码密钥、验证码/密码日志和未加约束的原始 SQL 不作为生产默认值；历史实现与旧文档可从 Git 记录恢复。
