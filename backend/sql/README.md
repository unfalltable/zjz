# 数据库 SQL

本目录保存数据库建表和版本化迁移 SQL，以及 Drizzle 的 `meta/` 迁移记录。现有 SQL 文件已从原迁移目录整体移动，内容不变。

新数据库按迁移序号依次执行 SQL；已有数据库仅应用未执行的迁移。不要重复执行所有建表文件，不要修改已应用的历史 SQL 或元数据。

表结构的 TypeScript 定义在 `../api/db/schema.ts`。需要新增或修改表结构时，在仓库根目录执行 `npm run db:generate` 生成追加迁移，检查 SQL 后再通过目标环境的迁移流程应用。本次目录调整没有生成新迁移，也没有修改或清空任何数据库。

构建时仍会将这些迁移复制到 `dist/.openai/drizzle/`，兼容现有托管约定；该构建输出名称不影响本目录采用 `sql/`。
